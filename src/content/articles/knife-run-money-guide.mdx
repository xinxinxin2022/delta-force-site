## What is a Knife-Run?

A **knife-run** means entering a Havoc extraction match with:
- **No weapons** (or only a melee knife)
- **No armor**
- **No grenades**
- **No gear whatsoever**

Your goal: **Extract with whatever loot you find**, selling it for pure profit.

### Why Knife-Running Works

| Factor | Detail |
|--------|--------|
| **Zero Investment** | No gear cost = pure profit |
| **No Loss Risk** | Die = lose nothing |
| **High Success Rate** | 70-90% extraction rate |
| **Scalable** | Do 10-20 runs per day |
| **Builds Capital** | Funds your main loadouts |

## Best Knife-Run Routes by Map

### Prison Map Knife-Run (Safest — 85% Success)

**Route: Sewer Exit (6-8 minutes)**

```
Step 1: Spawn → Sprint to Workshop (west)
Step 2: Grab C4 from Workshop table
Step 3: Sprint to Sewer Exit (southwest)
Step 4: Blow grate with C4 (5 seconds)
Step 5: Extract through sewer
```

**Loot Target:** C4 alone is worth 5,000-8,000
**Bonus Loot:** Grab tool parts from Workshop (+5,000-10,000)
**Total Expected Value:** 10,000-18,000 per run

**Why It's Safe:**
- Sewer Exit is the least contested extraction
- Workshop is accessible from most spawns
- C4 is always available in Workshop

<Callout type="warning" title="Avoid Main Gate">
60% of all deaths happen at the Main Gate. Never knife-run to Main Gate.
</Callout>


### Bakhsh Map Knife-Run (Highest Value — 70% Success)

**Route: Research Lab Bunker (8-12 minutes)**

```
Step 1: Spawn → Sprint to Research Labs (south)
Step 2: Grab tech items from lab tables
Step 3: Head to Research Lab Bunker lever
Step 4: Pull lever (3-5 seconds, vulnerable!)
Step 5: Defend for 30-60 seconds
Step 6: Extract via underground tram
```

**Loot Target:** Tech items worth 15,000-30,000
**Bonus Loot:** Keycards from Control Tower (+5,000-10,000)
**Total Expected Value:** 20,000-40,000 per run

**Why It's Valuable:**
- Research Labs have highest-value loot
- Underground bunker is safest extraction
- Tech items sell for premium prices

**Risk Factor:**
- Lever pull alerts entire map
- Must defend for 30-60 seconds
- Bring smoke grenades (found on map)


### Dam Zero Map Knife-Run (Medium Risk — 80% Success)

**Route: South Bridge Extract (10-14 minutes)**

```
Step 1: Spawn → Move along south perimeter
Step 2: Loot abandoned vehicles (parts, ammo)
Step 3: Head to South Bridge extraction
Step 4: Wait for extraction timer
Step 5: Extract via bridge
```

**Loot Target:** Vehicle parts worth 8,000-15,000
**Bonus Loot:** Ammo crates (+3,000-5,000)
**Total Expected Value:** 11,000-20,000 per run

**Why It Works:**
- South perimeter has less traffic
- Vehicle parts are lightweight and valuable
- Bridge extraction is reliable

**Risk Factor:**
- Long run to extraction (exposed)
- Open terrain (sniper danger)
- Bring found armor if available


### Longbow Valley Knife-Run (Lowest Risk — 75% Success)

**Route: Valley Floor Extract (8-10 minutes)**

```
Step 1: Spawn → Stay in valley floor (avoid ridges)
Step 2: Loot supply crates along floor
Step 3: Head to Valley Floor extraction
Step 4: Extract quickly
```

**Loot Target:** Supply crate items worth 6,000-12,000
**Total Expected Value:** 6,000-12,000 per run

**Why It's Safe:**
- Valley floor has cover from ridges
- Less player traffic
- Short extraction time

**Trade-off:** Lower loot value but highest safety


## Advanced Knife-Run Strategies

### Strategy 1: The C4 Loop (Prison)

Maximize Prison knife-runs by **reusing C4**:

```
Run 1: Grab C4 → Extract via Sewer → Keep C4
Run 2: Already have C4 → Grab more loot → Extract
Run 3+: Repeat until C4 is consumed
```

**Profit Increase:** +30-40% per run (no need to find C4 each time)

**Note:** C4 degrades after 3-4 uses. Always grab fresh C4 when possible.


### Strategy 2: The Keycard Snatch (Bakhsh)

Target **keycards** specifically for maximum profit:

```
Step 1: Spawn → Sprint to Control Tower
Step 2: Loot keycards from command center
Step 3: Extract via nearest safe lever
```

**Keycard Values:**
- Workshop Keycard: 15,000-25,000
- Lab Keycard: 20,000-35,000
- Commander Keycard: 30,000-50,000

**Expected Value:** 20,000-40,000 per successful keycard run


### Strategy 3: The Team Knife-Run (3-4 Players)

Coordinate with friends for **maximum efficiency**:

```
Player 1: Pulls lever at safest extraction
Player 2: Grabs high-value loot
Player 3: Grabs secondary loot
Player 4: Covers/defends extraction
```

**Benefits:**
- One player defends while others loot
- Shared extraction (all extract together)
- 3-4× the profit per match time

**Profit per Player:** 15,000-30,000 per coordinated run


### Strategy 4: The Daily Challenge Rush

Focus on **daily challenges** that reward extraction:

```
Check daily challenges → Focus on relevant maps
Example: "Extract 3 times" → Do 3 quick knife-runs
Example: "Loot 5 items" → Grab 5 cheap items, extract
```

**Bonus Income:** Challenge rewards often equal 1-2 knife-runs worth of profit

### Sell vs. Keep Decision Matrix

Not all loot should be sold. Here's when to **keep items** for your own use:

| Item Type | Sell When | Keep When |
|-----------|-----------|-----------|
| **Weapons** | Below 10K value | Above 10K or meta build |
| **Armor** | Below 5K value | Above 5K or high tier |
| **Ammo** | Always sell (stacks up) | Only if using that weapon |
| **Medical** | Always sell | Only if low on supply |
| **Keycards** | Always sell | Only if needed for route |
| **Tool Parts** | Always sell | Only if building weapons |
| **C4/Explosives** | Always sell | Only if needed for extraction |

## Knife-Run Mistakes to Avoid

### Mistake #1: Greeding for Too Much Loot
**Problem:** Trying to carry too much slows you down.
**Solution:** Prioritize high-value, low-weight items. Leave heavy loot behind.

### Mistake #2: Fighting When You Should Run
**Problem:** Engaging enemies during a knife-run.
**Solution:** You have no gear. **Run. Always run.** Your life is worth more than a fight.

### Mistake #3: Using Contested Extractions
**Problem:** Going to Main Gate or popular extractions.
**Solution:** Use hidden/low-traffic extractions (Sewer Exit, Bunker, etc.)

### Mistake #4: Not Checking Daily Challenges
**Problem:** Missing free bonus income.
**Solution:** Always check challenges before starting your session.

### Mistake #5: Inconsistent Schedule
**Problem:** Playing randomly, not building momentum.
**Solution:** Set a daily schedule. Consistency beats intensity.
