## Sensitivity Settings — The Foundation

Sensitivity is the **most important setting** in any FPS game. Get it wrong and you'll miss every shot. Get it right and you'll wonder how you ever played differently.

### PC Sensitivity (Mouse & Keyboard)

#### Recommended Starting Point

| Setting | Value | Notes |
|---------|-------|-------|
| **Mouse DPI** | 800 | Standard for most gamers |
| **In-Game Sensitivity** | 1.0-1.5 | Start here, adjust as needed |
| **ADS Sensitivity** | 0.8-1.0 | Slightly lower than hip-fire |
| **Scope Sensitivity (2x)** | 0.7-0.9 | Lower for precision |
| **Scope Sensitivity (4x)** | 0.5-0.7 | Even lower for long range |
| **Sniper Scope Sensitivity** | 0.3-0.5 | Very low for stability |

#### eDPI Calculation

```
eDPI = Mouse DPI × In-Game Sensitivity

Recommended Range: 800-1200 eDPI

Examples:
800 DPI × 1.0 = 800 eDPI ✅ (precision-focused)
800 DPI × 1.5 = 1200 eDPI ✅ (balanced)
800 DPI × 2.0 = 1600 eDPI  (too high)
1600 DPI × 0.5 = 800 eDPI ✅ (same as 800×1.0)
```

<Callout type="tip" title="Finding Your Perfect Sensitivity">
Go to firing range. Try to track a moving target in a straight line. If you overshoot → lower sensitivity. If you undershoot → raise it. Repeat until smooth.
</Callout>

### Mobile Sensitivity (Touch Controls)

#### Recommended Starting Point

| Setting | Value | Notes |
|---------|-------|-------|
| **Camera Sensitivity** | 50-60 | Standard starting point |
| **ADS Sensitivity** | 40-50 | Lower for precision |
| **Scope Sensitivity (2x)** | 35-45 | Precision at mid-range |
| **Scope Sensitivity (4x)** | 25-35 | Stability at long range |
| **Gyroscope Sensitivity** | 30-40 | If using gyro aim |
| **Gyroscope ADS** | 20-30 | Fine control when scoped |

#### Mobile Pro Tips

**1. Use 4-Finger Claw Layout**
- Left thumb: Movement
- Right thumb: Camera/aim
- Left index: Fire button
- Right index: ADS/scope button

**2. Enable Gyroscope for Fine Adjustments**
- Gyro is perfect for micro-adjustments
- Keep gyro sensitivity lower than touch
- Practice in firing range first

**3. Custom Button Layout**
- Move fire button to top-right (easy index reach)
- Place ADS button near thumb rest position
- Add crouch/prone buttons within thumb reach

```

│                                     │
```

## Settings Quick-Start Guide

### New Player Setup (5 Minutes)

1. **Set mouse DPI to 800** (PC) or default (mobile)
2. **Set in-game sensitivity to 1.0** (PC) or 50 (mobile)
3. **Set graphics to Low/Competitive** (max FPS)
4. **Turn OFF motion blur and depth of field**
5. **Turn ON HRTF/3D audio**
6. **Set SFX volume to 100%, music to 10%**
7. **Go to firing range and test**

### Fine-Tuning (After 10 Matches)

1. **If overshooting targets:** Lower sensitivity by 0.1
2. **If undershooting targets:** Raise sensitivity by 0.1
3. **If FPS is low:** Lower graphics settings further
4. **If can't hear footsteps:** Check audio output device
5. **If buttons feel wrong:** Adjust keybind layout
