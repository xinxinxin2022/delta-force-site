## Extraction Point Details

### 1. Main Gate (High Risk, High Reward)

**Location:** South-center of map, visible from most of the yard

**Why Use It:**
- Central location, easy to reach from anywhere
- No requirements or conditions
- Vehicle spawn point (fast extraction)

**Why Avoid It:**
- **Most contested extraction** on the map
- Open area with minimal cover
- Common camping spot for third-parties

**Strategy:**
- Approach from the Administration Building side (more cover)
- Use smoke grenades before crossing the yard
- Have your weapon ready — expect fights here
- **Best for:** Final moments when other extractions are contested

<Callout type="warning" title="Main Gate Warning">
60% of all player deaths happen at the Main Gate. Only use it when necessary.
</Callout>


### 2. North Tunnel (Medium Risk)

**Location:** North-east corner, behind Cell Block B

**Why Use It:**
- Less traffic than Main Gate
- Covered approach from Cell Block A
- Good for north-side loot runs

**Why Avoid It:**
- Single entrance/exit (can be camped)
- Limited cover inside tunnel
- Dark lighting (hard to spot enemies)

**Strategy:**
- Clear the tunnel entrance before entering
- Use flashlight or night vision if available
- **Best for:** Players looting Cell Block A


### 3. Rooftop Helipad (Very High Risk)

**Location:** Top of Administration Building (center)

**Why Use It:**
- Most secure extraction IF you reach it
- Excellent sightlines to spot enemies
- High prestige (bragging rights)

**Why Avoid It:**
- **Requires climbing 4 flights of stairs**
- Stairwell is a death trap (common ambush spot)
- Open rooftop with no cover
- Everyone can see you coming

**Strategy:**
- Only attempt with full squad support
- Clear the stairwell floor by floor
- Bring smoke grenades for rooftop cover
- **Best for:** Confident squads with good communication

<Callout type="tip" title="Helipad Pro Tip">
The helipad extraction gives **bonus XP** for the difficulty. Worth it if you can pull it off.
</Callout>


### 4. Sewer Exit (Low Risk, Hidden)

**Location:** South-west corner, near Workshop

**Requirements:**
- C4 explosive (found in Workshop or brought in)
- 5 seconds to blow the grate

**Why Use It:**
- **Least contested extraction** on the map
- Hidden from most sightlines
- Fast extraction once opened

**Why Avoid It:**
- Requires C4 (inventory space)
- Loud explosion alerts nearby players
- Limited escape routes if ambushed

**Strategy:**
- Grab C4 from Workshop early
- Approach from the south side (less traffic)
- Blow the grate and extract immediately
- **Best for:** Solo players and knife-runners


### 5. Watchtower Ladder (Medium Risk)

**Location:** East watchtowers

**Requirements:**
- Ladder must be in "down" position (random chance)
- Climb time: 8 seconds (vulnerable)

**Why Use It:**
- Elevated position (good for snipers)
- Less traffic than Main Gate
- Good sightlines while waiting

**Why Avoid It:**
- Ladder may not be available (RNG)
- 8-second climb is deadly if spotted
- Limited cover on tower platform

**Strategy:**
- Check ladder status before committing
- Have a teammate cover you while climbing
- **Best for:** Players with sniper rifles


### 6. Workshop Door (Low Risk, Keycard Required)

**Location:** West Workshop building

**Requirements:**
- Workshop Keycard (found in Administration)
- 3 seconds to swipe and open

**Why Use It:**
- Very secure once inside
- Low traffic area
- Can loot Workshop on the way out

**Why Avoid It:**
- Keycard required (must loot Admin first)
- Single exit point
- Confined space if ambushed

**Strategy:**
- Loot Administration Building for keycard
- Clear Workshop before extracting
- **Best for:** Players who already have the keycard


### 7. Yard Fence Break (Medium Risk, Team Required)

**Location:** East fence line

**Requirements:**
- 2 players to open simultaneously
- 10 seconds to cut through fence

**Why Use It:**
- Unconventional extraction (enemies don't expect it)
- Good for coordinated squads
- Accessible from Yard area

**Why Avoid It:**
- Requires 2 players (solo impossible)
- 10-second opening time (very vulnerable)
- Open area during extraction

**Strategy:**
- Coordinate with a teammate
- Use smoke grenades during opening
- Have a third teammate cover if 3-squad
- **Best for:** Premade duos/trios

## Optimal Loot Routes

### Route 1: High-Risk High-Reward (15 minutes)

```
Spawn → Cell Block A → Administration Safe → Rooftop Helipad Extract
```

**Loot Value:** ⭐⭐⭐⭐⭐ (50,000-100,000+)
**Survival Rate:** ~30%

**Steps:**
1. Spawn and rush Cell Block A (north)
2. Clear commander room for military gear
3. Move to Administration Building
4. Open safe for keycards and cash
5. Attempt Rooftop Helipad extraction

<Callout type="warning" title="High Risk Warning">
This route puts you in the most contested areas. Only attempt with a squad.
</Callout>


### Route 2: Balanced Approach (12 minutes)

```
Spawn → Workshop → Cell Block B → Sewer Exit Extract
```

**Loot Value:** ⭐⭐⭐ (20,000-40,000)
**Survival Rate:** ~65%

**Steps:**
1. Spawn and head to Workshop (west)
2. Grab C4 and tool parts
3. Move through Cell Block B (south)
4. Loot cells for ammo and meds
5. Extract via Sewer Exit

**Best for:** Solo players and beginners


### Route 3: Quick Knife-Run (8 minutes)

```
Spawn → Grab C4 → Sewer Exit Extract
```

**Loot Value:** ⭐ (5,000-10,000)
**Survival Rate:** ~85%

**Steps:**
1. Spawn and sprint to Workshop
2. Grab C4 only (ignore other loot)
3. Run to Sewer Exit
4. Blow grate and extract

**Best for:** Daily challenges and quick currency


## Knife-Run Routes (Zero Investment)

### Knife-Run Strategy

Knife-running means **entering with no gear** and extracting with whatever you find. The Prison is excellent for this due to multiple low-risk extractions.

### Best Knife-Run Routes

**Route A: Sewer Exit (Safest)**
```
Spawn → Workshop (grab C4) → Sewer Exit
Time: 6-8 minutes
Success Rate: ~90%
```

**Route B: Watchtower Ladder (Fastest)**
```
Spawn → Yard → Check ladder → Climb and extract
Time: 5-7 minutes
Success Rate: ~70% (ladder RNG)
```

**Route C: Workshop Door (If Keycard Found)**
```
Spawn → Admin (find keycard) → Workshop Door
Time: 10-12 minutes
Success Rate: ~50%
```

<Callout type="tip" title="Knife-Run Tip">
Do 3-4 knife-runs per session to build up starting capital. Average profit: 15,000-25,000 per run.
</Callout>


## Prison Map Pro Tips

### Tip #1: Learn the Sound Cues
The Prison has **distinctive acoustics**. You can hear:
- Footsteps echoing in Cell Blocks
- Door swipes in Administration
- C4 explosions from across the map

**Use this to track enemy movement.**


### Tip #2: Control the Administration Building
Whoever holds Administration controls the match:
- Access to keycards (Workshop Door extraction)
- High-value safe loot
- Central position for rotations
- Rooftop Helipad access

**Priority target for squads.**


### Tip #3: Use the Yard for Long-Range
The Yard area is perfect for **sniper rifles**:
- Clear sightlines to Watchtowers
- Cover behind concrete barriers
- Less traffic than Cell Blocks

**Bring a sniper rifle if you prefer long-range combat.**


### Tip #4: Time Your Extractions
Extraction timing is critical:
- **Early game (0-10 min):** Loot freely, avoid fights
- **Mid game (10-15 min):** Start moving to extraction
- **Late game (15-20 min):** Expect heavy contest at extractions

**Leave buffer time — don't wait until 19 minutes to extract.**


### Tip #5: Squad Composition Matters
For Prison, ideal squad roles:
- **1x Assault Rifle:** Close-quarters Cell Block clearing
- **1x Sniper Rifle:** Yard and Watchtower control
- **1x Support/SMG:** Flanking and backup

**Coordinate loadouts before dropping.**
